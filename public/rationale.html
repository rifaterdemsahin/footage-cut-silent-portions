🧠 Why this pipeline exists

Talking-head footage is mostly waiting. The useful product is the spoken bits as files an editor — or an agent — can grab without opening a timeline.

🎯 The job

  • 📥 Input: one long take (here, output alpha.mp4 → movies/alpha.mp4).
  • 🤫 Detect: stretches of audio below a noise floor for ≥ 0.5 s.
  • 🩹 Pad: keep ~120 ms around each keep-region so words are not clipped.
  • 📁 Footage: each keep-region is its own MP4 in output/alpha/clips/.
  • 🧵 Master: those clips concatenated to alpha_nosilence.mp4.
  • 📋 Receipt: last-run.json with timings so performance.html stays honest.

🆚 Why not DaVinci Resolve for this step?

Resolve is the right tool to finish a video. It is the wrong tool to batch-strip silence from raw takes:

  • 🖱️ Resolve wants a human in a GUI. This wants a command an agent can retry.
  • 📁 Resolve gives you one timeline. This gives you numbered clips on disk — the actual footage to reuse.
  • 🔁 50 files in a folder is a for loop here and a day of clicking in Resolve.
  • 🧪 Threshold, min-silence, and padding are data. They belong in JSON, not in undocumented playhead habits.
  • 💸 Resolve Studio / Fairlight is heavy for “delete the quiet parts.” FFmpeg already has silencedetect.

Hand the nosilence master (or the clip folder) to Resolve afterwards if you need color, titles, or music. Do not start there.

🔬 Design choices

ChoiceWhy
🎚️ Auto threshold This file’s mean volume is −48.4 dB. A textbook −30 dB cut 88% of it and ate speech. Auto uses max(mean+8, peak−20) → −40 dB.
🎧 Audio-only detect ffmpeg -vn so silence detection does not decode 1080p. 220 ms vs several seconds.
🧩 Per-clip encode, then copy-concat One giant filter_complex is brittle at 25+ segments. Clips on disk are the product; concat is a bonus master.
⚡ libx264 veryfast CRF 20 Fast enough for an agent loop, sharp enough for 1080 talking-head. Not a delivery grade.
🧹 Min clip 0.25 s + merge 0.25 s Stops 80 ms blips and stitches speech that silence-detect split on a breath.
🧾 JSON report If the agent “fixed” something, you can see whether duration and clip count actually changed.

⚠️ What this will not do

  • 🗣️ It does not transcribe. Quiet speech and noise look similar to a dB gate.
  • 🎵 It will cut intentional pauses, jokes that land late, and room tone you wanted.
  • 🎨 It will not match color, stabilize, or loudness-normalize beyond the encode.
  • ☁️ GitHub Pages will not process your disk. That is the local Node server.
