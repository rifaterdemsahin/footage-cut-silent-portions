🆚 Why this instead of DaVinci Resolve?

      

        
          
✂️ This tool🎛️ DaVinci Resolve

        
        
          

            Job
            One job: delete dead air and dump usable clips.
            Full NLE: color, Fairlight, Fusion, delivery, timeline taste.
          

          

            Time to first cut
            Drop file → one command → ~12 seconds for a 4‑minute 1080p clip.
            Create project, import, inspect waveform, mark, ripple delete, export.
          

          

            Repeatability
            Same flags, same cuts, log + JSON report every run.
            Human timeline. Hard to replay identically across 50 files.
          

          

            Agent / CI
            Headless. An agent can run, watch the log, fix FFmpeg, rerun.
            GUI. No good “fix the timeline and push” loop for an agent.
          

          

            Cost / install
            Node + FFmpeg. No 4 GB app, no project database.
            Studio features, GPU, project files, export queue.
          

          

            When Resolve wins
            Not for grade, titles, multicam, music edits, or picture lock.
            Finish the film. This tool only feeds you clean speech clips.
          

        
      

      
Use Resolve when you are editing a story. Use this when you are harvesting speech from a long take so the NLE never sees the silence.
