🖥️ What to expect on other machines

  • 🤫 Detect scales with audio length, not resolution. A 20‑minute file is still usually under a few seconds.
  • 🎞️ Encode scales with kept video, not source length. More speech → longer export. 1080p veryfast is roughly 0.15–0.2 s per kept second here.
  • 🧠 Do not use a fixed −30 dB on quiet lavs. Auto saved this run from a 28 s false cut.
